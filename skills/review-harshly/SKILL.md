# 厳格レビュー（敵対的検証・証拠優先）

`$ARGUMENTS` を、作者の意図を知らない第三者として監査する。目的は指摘数ではなく、再現可能で影響評価の正しい欠陥を得ること。

観点リストは [references/review_blind_spots.md](references/review_blind_spots.md) にある。
**全文を読み込まない。** レンズごとに対応する節だけを読む（下の対応表を参照）。

## 使い分け

- **高リスク**（本番データ更新、認可・秘密、金銭、不可逆変更、または対象が複数コンポーネント）: 5レンズを独立サブエージェントで並列実行し、必ず反証する。
- **通常**（限定された変更・読み取り専用・影響範囲が明確）: correctness と該当する追加1レンズだけを実行し、反証はメインが行う。

曖昧なら高リスクを選ぶ。高リスクでレンズ数を減らして節約してはならない。

## Phase 0: 一度だけ作る監査マニフェスト

最初に `docs/audit-YYYY-MM-DD/manifest.md`（既存なら更新）へ次だけを短く書く。

1. 対象ファイルと基準コミット
2. 成果物の目的と、測定可能な合格条件
3. 実行環境・権限境界
4. 既知の事実、再検証不要な測定値、禁止操作
5. レンズ別の読むべきファイルと、未解決の問い

マニフェストは各エージェントへの長い説明の代替である。エージェントにはパスだけを渡し、同じ説明・全ファイル・全コマンド出力をプロンプトへ複製しない。

## Phase 1: 独立検出

高リスクでは Agent ツールで5レンズを同時に起動する。各エージェントへの指示は、次の共通文とレンズ名・マニフェストのパスだけにする。

```
第三者の成果物を静的監査する。作者の意図を推測して擁護しない。
監査マニフェスト <path> を読み、自分のレンズに割り当てられたファイルと未解決の問いだけを先に確認する。

証拠規律:
- 事実は、該当するファイル:行または読み取りコマンドの要約で裏付ける。ファイル全体やSOQLの全行を会話へ貼らない。
- 既知事実は再取得しない。追加の照会は、指摘の再現または反証に必要なものだけにする。
- 1つの仮説につき、関連する最小のコード範囲を読んで成立/不成立を決める。成立しない仮説は捨て、探索を続けない。
- 欠陥を確定した時点でレンズ報告へ追記する。指摘が無ければ「確認済み範囲」と残余リスクだけを記録し、欠陥を捏造しない。
- 同じ根本原因の派生は1件に統合する。各レンズは原則3件、最大5件の証拠付き指摘で停止する。

出力する欠陥は、深刻度、場所、具体的な入力→結果、機序、確認方法、修正案を含める。
```

各エージェントは `~/.claude/skills/review-harshly/references/review_blind_spots.md` の「思考パターン」表と**自分のレンズに対応する節だけ**を読む。全チェックリストを全員が再読しない。

- correctness: E（前提と証拠）、F（設計の順序）
- environment: A（実行環境の差）
- security: B（権限境界と外部入力）
- operability: C（運用と異常系）
- succession: D（正本と引き継ぎ）

### 収集ルール

- 大量データは `COUNT`、`GROUP BY`、対象IDを指定した絞り込みで確認し、標準出力は件数・差分・先頭数件に限る。
- 後で必要な生データは、監査ディレクトリの `evidence/` にコマンド・日時・要約とともに保存する。会話履歴をデータ置き場にしない。
- 1レンズが対象外のファイルまで横断し始めたら、マニフェストに問いを追加して別レンズへ渡す。重複探索しない。

## Phase 2: 反証

別のサブエージェントに、各レンズ報告とマニフェストだけを渡す。報告文を信用せず、引用済みの行と最小限の周辺実装を読み直させる。

既定は棄却。次の両方を満たすものだけ維持する。

1. 記載された入力→結果が実装・設定と一致する。
2. 実害が深刻度に見合う。

各指摘を「維持 / 深刻度修正 / 棄却」とし、重複は根本原因1件へ統合する。追加探索や新しい指摘の発掘はしない。

## Phase 3: 報告と学習

反証を通ったものだけを深刻度順に報告する。スコアは出さない。指摘がゼロでも、確認済み範囲と未検証の残余リスクを明示する。

既存の観点で拾えなかった欠陥があれば、根本原因を汎用化して
`references/review_blind_spots.md` の追記規則に従い1項目だけ追加する。

## 禁止事項

- メイン文脈だけで高リスク監査を完結させる
- 「問題ない」と結論し、確認範囲を示さない
- 再現手順または証拠のない指摘
- 本番の書込み操作
